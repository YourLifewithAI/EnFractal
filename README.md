## First map prototype

The [Barton Creek map](maps/barton_creek/README.md) is the first implementation: a reproducible source-to-package builder and a lightweight Godot viewer centered at **30.250924, -97.810494** near Barton Creek Square and the MoPac / Highway 360 area. It includes measured USGS terrain, mapped OSM roads, trails, creeks and building footprints, plus clearly illustrative vegetation. The playable-world systems in the roadmap remain future work.
