# Source and derived-data notices

The source archive, attribution and evidence travel with this package. File hashes, acquisition times and exact request URLs are in `sources/2026-10-02/sources.json` and `supplemental_sources.json`. The generated `package/manifest.json` pins those records, source bytes, configuration, builder code and dependency versions. A metadata entry for a possible future source is **not permission to redistribute that source**.

## Data included

- **Terrain:** USGS 3D Elevation Program (3DEP) bare-earth dynamic image service, requested at 2 m sample spacing. USGS-produced 3DEP data are public domain. Retain the source acknowledgement and exact acquisition record. [USGS 3DEP products and services](https://www.usgs.gov/3d-elevation-program/about-3dep-products-services). An export's sample spacing is not a claim of native source resolution or measured accuracy.
- **Mapped feature database, boundary and landing alignment:** © OpenStreetMap contributors, made available under the [Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/). These OSM-derived databases are distributed under ODbL 1.0, separately identifiable from terrain and software. Preserve attribution and comply with applicable database share-alike/access obligations on redistribution. [OpenStreetMap copyright and attribution](https://www.openstreetmap.org/copyright).
- **Preview:** produced from the separately identifiable USGS terrain and OSM-derived database. Display “© OpenStreetMap contributors” with the preview and retain the ODbL source link/notice. It is a source inspection graphic, not aerial imagery or the game's art target.

The OSM archive contains public OSM editing metadata. The application feature database exports geographic features and source element IDs rather than contributor names. The original database snapshot is kept for reproducibility and ODbL access.

## Not included

No aerial/satellite photographs, street-view images, City of Austin geometry/imagery, Commons photographs, or proprietary map tiles are included. `source_registry.json` records candidates and source-specific rights/coverage gates. Do not infer that public accessibility, an empty service copyright field, or an open-data catalogue listing licenses every upstream image or derivative product.

No change to the repository's software license is made by these data notices. Photos acquired later need their own creator, source URL, license version, attribution, modification notice and redistribution decision.
