# Barton Creek source and feature rights

The GeoTIFF [`usgs_3dep_2m.tif`](usgs_3dep_2m.tif) was exported from the [USGS 3DEP bare-earth dynamic elevation service](https://elevation.nationalmap.gov/arcgis/rest/services/3DEPElevation/ImageServer) for the bounded area and query recorded in [`sources.json`](sources.json). [USGS states that 3DEP products are free of charge without use restrictions](https://www.usgs.gov/3d-elevation-program/about-3dep-products-services). Credit: **U.S. Geological Survey, 3D Elevation Program (3DEP)**. The derived height grid in the game package retains that credit.

The four `osm_*.osm.gz` files are a bounded OpenStreetMap contributor snapshot. The derived [`features.json`](../../../game/maps/barton_creek/features.json) is distributed as a geospatial database under the **Open Database License 1.0 (ODbL)**. Credit: **© OpenStreetMap contributors**. The full license and attribution rules are at [OpenStreetMap Copyright](https://www.openstreetmap.org/copyright) and the [ODbL legal text](https://opendatacommons.org/licenses/odbl/1-0/). The raw snapshot remains available here so recipients can inspect or reuse the underlying data. Keep this file and the attribution when redistributing the game package or derived database.

The Python and Godot code, map schema, game rules and future player changes are separate from the OSM feature database. All generated tree positions and estimated building heights included in `features.json` are provided with the ODbL database. The 2D and 3D previews are produced works and display attribution. Source metadata, retrieval timestamps, bounding boxes and checksums are in [`sources.json`](sources.json).
