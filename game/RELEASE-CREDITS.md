# EnFractal native build: notices

Avatar blockouts, the placeholder room, the painterly reference assets (oak and juniper meshes, painted textures, shaders) and procedural materials are original EnFractal work.

This is an unsigned Windows development build. It contains a hand-built placeholder room, not a captured space. Art, the capture pipeline, the AI companion connection and room persistence are not included. Keep the executable, PCK and adjacent runtime directory together.
